## Features

### Brand-Agnostic
No hardcoded logos, vendor names, or domain names. Everything loads directly from your FOSSBilling company settings (`company.name`, `company.logo_url`, `company.signature`), with clean neutral fallbacks when a field is empty.

### 5 Color Presets
Switch palettes with one click in the admin panel:
- **Corporate Navy** (`#0e5077`, default): Classic web hosting navy.
- **Cobalt** (`#0a58ca`): Vibrant blue.
- **Slate** (`#2c3e50`): Neutral charcoal gray.
- **Teal** (`#0e7490`): Deep ocean teal.
- **Emerald** (`#057a55`): Forest green.

### 4-Step Order Flow
Walks clients through ordering without getting lost:
1. **Choose a Plan**: Product cards with pricing and billing cycles.
2. **Domain Options**: Register a new domain, transfer one in, or point an existing domain.
3. **Configure**: Pick billing terms, fill in server options, and set custom product fields.
4. **Checkout**: Review cart totals, enter promo codes, and complete the order.

### Dedicated Domain Ordering
- Real-time domain search and availability check.
- Clear pricing breakdown for registration, renewal, and transfer fees.
- Inline guidance for nameservers and DNS propagation.

### Dashboard Overview
Quick stats for active services, unpaid invoices, open tickets, and account balance, plus recent activity tables so clients see what needs attention right away.

### Invoices and Billing
- Separate tabs for unpaid invoices and paid receipts.
- Detailed invoice view with itemized charges, tax breakdown, and company billing info.
- Clean printable invoice layout and direct PDF downloads.
- Works with all standard FOSSBilling payment gateways.

### Support Tickets
- Filter tickets by department and status.
- Threaded conversation view with staff identity badges, timestamps, and quote reply shortcuts.
- Form validation and flash notifications on replies and ticket submissions.

### Knowledge Base Hub
- Modern categorized help center with search.
- Clean category and article views with quick links to related guides.

### Service Management
Clients can view service details (IP address, renewal date, billing cycle), generate early renewal invoices, or submit cancellation requests directly from the portal.

### Profile and Security
Clients can update contact info, change passwords, select display currency, and manage their API keys.

### Admin Settings
Customize theme options in your FOSSBilling Admin Panel (**System &rarr; Themes &rarr; Settings for FossModernicus**):
- Pick a color palette.
- Set light and dark logo URLs.
- Add a global Markdown announcement banner.
- Configure up to 5 custom footer links.
- Add custom CSS or JavaScript tracking snippets without touching template files.

## Installation

Tested and verified on FOSSBilling v0.8.x (including v0.8.8 and the latest v0.8.9 release).

### Method 1: Download Release Archive (Recommended)

1. Download [**`fossmodernicus-v1.0.3.zip`**](https://github.com/administrakt0r/fossmodernicus/releases/latest/download/fossmodernicus-v1.0.3.zip) (or pick a version from [GitHub Releases](https://github.com/administrakt0r/fossmodernicus/releases)).
2. Unzip into your FOSSBilling themes folder:
   ```bash
   unzip fossmodernicus-v1.0.3.zip -d /path/to/fossbilling/themes/fossmodernicus
   ```
3. Set file permissions:
   ```bash
   chmod -R 755 /path/to/fossbilling/themes/fossmodernicus
   ```
4. In your FOSSBilling Admin Panel, go to **System &rarr; Themes**, find **FossModernicus** under **Client Area Themes**, and click **Set as Default**.

### Method 2: Git Clone

```bash
cd /path/to/fossbilling/themes
git clone https://github.com/administrakt0r/fossmodernicus.git fossmodernicus
chmod -R 755 fossmodernicus
```

## Theme Settings

Once activated, configure options in **System &rarr; Themes &rarr; Settings for FossModernicus**:

- **Color Palette**: Pick Corporate Navy, Cobalt, Slate, Teal, or Emerald.
- **Branding Logos**: Add URLs for light and dark mode logos.
- **Announcement Banner**: Display a global alert banner with Markdown formatting.
- **Footer Links**: Add up to 5 custom footer navigation links.
- **Custom Assets**: Add custom CSS or JavaScript snippets without editing theme templates.

### Clearing Cache
If changes do not show up right away, clear the FOSSBilling template cache:
```bash
rm -rf /path/to/fossbilling/data/cache/*
```
